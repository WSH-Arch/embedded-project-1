# 四足机器狗 · 舵机控制系统（STM32U575）

基于 STM32U575 + STM32CubeMX / HAL 库的四足机器人舵机控制工程：输出 4 路标准 50Hz PWM 波形驱动 4 个舵机，实现四条腿的独立角度控制与多组动作序列，按键触发动作切换。

## 功能概览

```
        STM32U575RITx
   ┌───────────────────────┐
   │  TIM3  CH1 / CH2      │───→ 舵机 1 / 舵机 2（PC7 / PC6）
   │  TIM15 CH1 / CH2      │───→ 舵机 3 / 舵机 4（PB15 / PB14）
   │  GPIOA PIN15          │───→ 蜂鸣器（提示音）
   │  GPIOA PIN12          │←─── 按键（低电平触发动作）
   └───────────────────────┘
```

## 舵机控制原理

模拟舵机由「直流电机 + 减速齿轮 + 电位器反馈 + 控制电路」组成，内部自带位置闭环。外部只需提供标准控制信号：

- 周期 **20ms（50Hz）**，高电平宽度 **0.5ms ~ 2.5ms** 对应角度 **0° ~ 180°**（1.5ms = 90°）

### 参数计算（本工程实际配置）

| 参数 | 取值 | 说明 |
|---|---|---|
| 定时器 | TIM3（CH1/CH2）、TIM15（CH1/CH2） | 每个定时器输出 2 路 PWM，共 4 路 |
| 预分频 PSC | 160 - 1 | 计数时钟 160MHz / 160 = **1MHz**，即每个计数 = **1μs** |
| 自动重装 ARR | 20000 | 20000 × 1μs = **20ms**，即 **50Hz** |
| 比较值 CCR | 500 ~ 2500 | 直接对应高电平的微秒数 |

角度换算（`Core/Src/Servo.c`）：

```c
__HAL_TIM_SetCompare(&htim3, TIM_CHANNEL_2, Angle / 180 * 2000 + 500);   /* 单位：μs */
```

即 0° → 500μs，90° → 1500μs，180° → 2500μs。

> `Servo_Angle1()` 中使用 `(180 - Angle)`，是因为该舵机在机构上为**镜像安装**，角度需反向计算。

## 引脚分配

| 功能 | 引脚 | 定时器通道 |
|---|---|---|
| 舵机 1（右前） | PC7 | TIM3_CH2 |
| 舵机 2（左前） | PC6 | TIM3_CH1 |
| 舵机 3（左后） | PB15 | TIM15_CH2 |
| 舵机 4（右后） | PB14 | TIM15_CH1 |
| 蜂鸣器 | PA15 | GPIO |
| 按键 | PA12 | GPIO（输入，低电平有效） |

## 动作序列

```c
void move1(void);   /* 舵机 1 在 0 / 50 / 90 / 120 度之间循环摆动 */
void move2(void);
void move3(void);
void move4(void);
```

主流程：初始化 → `Servo_Init()` 启动 4 路 PWM → 依次执行 `move1~move4` → 进入主循环，检测按键（PA12）触发动作。

## 编译与运行

1. 使用 Keil MDK5 打开 `MDK-ARM/lulu.uvprojx`
2. 确认已安装 STM32U5xx 器件支持包（Keil.STM32U5xx_DFP）
3. 通过 ST-Link / J-Link 下载程序
4. 注意：4 个舵机需**独立供电并共地**，直接由开发板取电会导致抖动或复位

## 调试记录

- 舵机抖动：用示波器核对 PWM 波形，确认周期 20ms、脉宽与目标角度一致；抖动主因是舵机供电不足与共地不良，改善供电后明显缓解
- 镜像安装的舵机角度反向：在接口层做 `180 - Angle` 转换，避免上层动作序列出现反向问题

## 已知局限与后续计划

**局限**
- 4 个舵机独立动作，未实现协调步态（对角步态相位配合），尚不能连续行走
- 无姿态反馈，缺少 IMU，无法判断机身倾斜
- 动作序列使用 `HAL_Delay()` 阻塞实现，执行期间 CPU 无法处理其他任务

**后续计划**
- 接入 MPU6050，使用互补滤波解算姿态
- 增加增量式 PID 角度闭环，实现舵机角度跟随
- 改为定时器中断驱动动作序列，配合四足相位表实现协调步态
- 接入 ESP8266，实现无线遥控
